# GreenlitX

> "Hollywood decides what gets made today. On GreenlitX, the audience does."

GreenlitX is an audience-driven film platform. Instead of studios and executives deciding in private which films get made, GreenlitX lets audiences help decide which movies get made — discovering projects, voting for the stories they want to see on screen, and supporting filmmakers.

## Current status

Early prototype development

## Planned features

- Film discovery
- Audience voting
- Filmmaker submissions
- Supporter accounts
- Simulated pledges
